Drift Harvest is an original arcade game played in the browser: pilot a harvester ship, collect energy crystals while hunting comets steer toward you, chain pickups to raise your score multiplier, survive escalating waves, and pick one of three ship refits after every second wave. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```

Controls: Arrows/WASD thrust · Space brake · P pause.
